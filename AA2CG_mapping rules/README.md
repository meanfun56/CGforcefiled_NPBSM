# CG Mapping Schemes (Bead Mapping Rules)

This folder contains the coarse-grained (CG) mapping schemes for 24 natural product-derived small molecules parameterized within the Martini 3 framework.

Each image illustrates how the all-atom (AA) structure is mapped onto Martini 3 CG beads. The file name corresponds to the molecule abbreviation.

## Molecules included

FER, EUG, CIN, OST, IMP, GEN, PUE, QUE, CAT, EMO, MET, PA, TPN, CNN, CIT, LIN, BOR, CNL, GPD, CAP, RES, LIG, EPH, MAG

## File naming

`MOL.png` (e.g., `FER.png`, `EUG.png`, ...)
